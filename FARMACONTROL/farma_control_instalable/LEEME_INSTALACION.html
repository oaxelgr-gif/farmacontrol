1Qué contiene esta carpeta

farma_control_instalable\ ├── INSTALAR.bat ← doble clic para instalar (una vez) ├── LEEME_INSTALACION.pdf ← esta guía ├── LEEME_INSTALACION.html ← esta guía (navegador) ├── herramientas\ ← acceso directo, respaldo, estado, íconos └── sistema\ ← el programa y su archivo .env
Datos iniciales: 1 usuario administrador (admin / 131004131004), 3 productos de prueba (códigos de barras 0000000000001, 0000000000002 antibiótico y 0000000000003) y 2 pacientes de prueba (PACIENTE PRUEBA UNO y DOS). Anaqueles base, métodos de pago, servicios y consultas del catálogo vienen igual que siempre.

3Instalar WSL 2 (base que usa Docker)

Clic derecho en Inicio → Windows PowerShell (Administrador) y ejecuta:

wsl --install --no-distribution
wsl --update
wsl --set-default-version 2

Si --no-distribution marca error, usa solo wsl --install. Reinicia la computadora.

4Instalar Docker Desktop

En PowerShell como administrador:

winget install -e --id Docker.DockerDesktop --accept-package-agreements --accept-source-agreements

Si winget no existe, descarga el instalador desde docker.com/products/docker-desktop y deja marcada la opción «Use WSL 2 instead of Hyper-V».

  1. Reinicia o cierra sesión.
  2. Abre Docker Desktop, acepta los términos (puedes saltar la creación de cuenta).
  3. En Settings → General deja activado «Start Docker Desktop when you sign in to your computer» y «Use the WSL 2 based engine».

Comprueba en PowerShell normal:

docker --version
docker compose version
docker run --rm hello-world

El último debe responder «Hello from Docker!».

5Copiar la carpeta

  1. Si la recibiste como farma_control_instalable.zip: clic derecho en el ZIP → Propiedades → marca Desbloquear → Aceptar.
  2. Descomprime para que quede exactamente en C:\farma_control_instalable.
Expand-Archive -Path "$env:USERPROFILE\Downloads\farma_control_instalable.zip" -DestinationPath C:\ -Force
No la pongas en el Escritorio, Descargas ni OneDrive: la sincronización y los permisos pueden bloquear archivos. Después de instalar no muevas ni renombres la carpeta (los accesos directos apuntan a ella).

6Instalar FarmaControl

  1. Abre Docker Desktop y espera a que diga Engine running.
  2. En C:\farma_control_instalable da doble clic en INSTALAR.bat y acepta el permiso de administrador. Si Windows muestra «Windows protegió su PC», elige Más información → Ejecutar de todas formas.
  3. Espera: la primera vez tarda de 5 a 15 minutos. El instalador hace todo esto solo:
    • construye y enciende las 3 partes del sistema (base de datos, sistema web y API);
    • detecta la IP de la computadora en la red;
    • abre los puertos 5010 y 8000 en el firewall y pone la red como Privada;
    • evita que la computadora se suspenda mientras está conectada a la corriente;
    • crea el acceso directo FarmaControl en el escritorio, la carpeta FarmaControl en el menú Inicio y el arranque automático al iniciar sesión.
  4. Al terminar abre el navegador en http://localhost:5010 y muestra la dirección para los demás equipos.

7Encender el sistema: acceso directo del escritorio

Doble clic en FarmaControl (ícono con el logo). Sin abrir ventanas negras:

  1. abre Docker Desktop si está cerrado y espera a que esté listo;
  2. actualiza la IP de la red (si el módem la cambió, el sistema se entera);
  3. enciende los contenedores y espera a que la base de datos responda;
  4. abre el navegador en el sistema y muestra un aviso con la dirección para otros equipos.

Además, el sistema arranca solo al iniciar sesión en Windows. En el menú Inicio → carpeta FarmaControl tienes: Apagar FarmaControl, RESPALDO, ESTADO, VER_DIRECCION y esta guía.

Docker Desktop solo funciona con una sesión de Windows iniciada. Para que tras un corte de luz todo vuelva solo, configura el inicio de sesión automático: Windows + R → netplwiz → desmarca «Los usuarios deben escribir su nombre y contraseña».

8Entrar desde otros equipos de la red

  • En el sistema: Reportes → Acceso desde otros equipos. Muestra la dirección (por ejemplo http://192.168.100.91:5010), un botón para copiarla, un código QR para los celulares y una hoja imprimible para pegar en el consultorio.
  • O en el menú Inicio → FarmaControl → VER_DIRECCION.
  • Los equipos deben estar en la misma red (mismo Wi-Fi o cable, no la red de invitados).
  • Reserva la IP de la computadora servidor en el módem («Reserva DHCP» o «IP fija») para que la dirección no cambie.

9Primer uso

  1. Entra con admin / 131004131004 y cámbiale la contraseña en Usuarios.
  2. Crea los usuarios: farmacéuticos con rol Farmacéutico; doctores con rol Administrador (el módulo clínico es exclusivo de ese rol).
  3. Clínica → Perfil médico: nombre, título, cédula, universidad, dirección, teléfono, WhatsApp y logos de la receta.
  4. Prueba una venta con los productos de prueba (incluye el antibiótico para ver el control de antibióticos) y una consulta con un paciente de prueba.
  5. Cuando todo funcione, elimina los 3 productos de prueba (Inventario) y da de baja los 2 pacientes (Clínica → Pacientes).
  6. Para que las recetas continúen tu numeración (si la última fue 1541), en PowerShell: 
    cd C:\farma_control_instalable\sistema
"ALTER TABLE recetas AUTO_INCREMENT = 1542;" | docker compose exec -T db sh -c 'mysql -uroot -p$MYSQL_ROOT_PASSWORD medicalife'

10Impresora de tickets

  1. Instala el controlador del fabricante (modelo exacto: POS-80, Epson TM-T20, Xprinter XP-80…). Un controlador genérico imprime «códigos raros».
  2. En las preferencias de la impresora elige papel de 80 mm.
  3. Al imprimir desde Chrome/Edge: Márgenes «Ninguno» y desactiva «Encabezados y pies de página».

Cada equipo imprime en su propia impresora: instala la térmica en la computadora de caja a la que está conectada.

11Respaldos y restauración

Menú Inicio → FarmaControl → RESPALDO. Guarda la base de datos en C:\farma_control_instalable\respaldos\respaldo_FECHA.sql (conserva los 30 más recientes). Hazlo al menos una vez por semana y copia el archivo a una USB o a la nube.

Restaurar un respaldo (cambia el nombre del archivo):

cd C:\farma_control_instalable\sistema
docker compose cp ..\respaldos\respaldo_20261006_1800.sql db:/tmp/r.sql
docker compose exec db sh -c 'mysql -uroot -p$MYSQL_ROOT_PASSWORD medicalife < /tmp/r.sql'
Nunca ejecutes docker compose down -v: la opción -v borra la base de datos. El archivo sistema\.env contiene las claves únicas de esta instalación: guarda una copia junto con tus respaldos.

12Actualizar el sistema

  1. Haz un respaldo.
  2. Reemplaza los archivos del programa dentro de sistema\ sin borrar sistema\.env ni la carpeta respaldos.
  3. Ejecuta de nuevo INSTALAR.bat. Reconstruye con el código nuevo; los datos se conservan.

13Problemas comunes

SíntomaSolución
«WSL 2 installation is incomplete» o Docker no arrancaPowerShell administrador: wsl --update y reinicia.
«Virtualization support not detected»Activa la virtualización en la BIOS (sección 2).
El acceso directo muestra «No se pudo iniciar FarmaControl»Abre Docker Desktop manualmente, espera «Engine running» y vuelve a intentar. El detalle queda en herramientas\ultimo_inicio.log.
Funciona en la PC pero no en otros equiposMisma red (no invitados), red de Windows en Privada, usa la dirección de Reportes → Acceso desde otros equipos. Si cambiaste la red, ejecuta de nuevo INSTALAR.bat para reabrir el firewall.
«port is already allocated»Otro programa usa el puerto 5010: en sistema\.env cambia WEB_PORT=5011 y ejecuta INSTALAR.bat.
La página no carga recién encendidaEspera 1–2 minutos (la base de datos tarda en arrancar). Revisa con ESTADO.
El ticket imprime texto raro (%!PS-Adobe)Controlador incorrecto de la impresora: ver sección 10.
No aparece el código QRNecesita internet para cargarse; la dirección escrita funciona igual.
